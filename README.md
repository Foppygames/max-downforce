# Max Downforce

## Overview

Max Downforce is a racing game programmed in Lua and LÖVE. The pseudo 3d style and gameplay is similar to the classic Pole Position. The player completes the game by completing each of a number of laps within a time limit. This is made difficult by computer controlled racers that get in the way.
